# 선행지표 기반 화장품 성분 트렌드 예측

PDRN이 유행하기 전에 어떤 데이터가 먼저 움직였는지 찾고, 같은 신호를 보이는 다음 후보 성분을 찾는 프로젝트입니다.
## 진행 상황

| 주차 | 내용 | 상태 |
|---|---|---|
| 1주차 | 키워드 사전 초안, 네이버 검색량·PubMed 논문 수 수집, 키워드 검수 1회차 | 완료 |
| 2주차 | 검색어 다듬기(검색식 정확도 점검), README 정리 | 완료 |
| 3주차 | KIPRIS 특허 수집·필터 점검, 세 데이터 통합 | 완료 |
| 4주차 | 시작점(onset)·시차·교차상관·그랜저 인과 분석 | 완료 |
| 5주차 | 후보 성분 점수화, 과거 시점 백테스트 | 완료 |
| 6주차 | 원료 사업 진입 가능성 검토 | 완료 |
| 7주차 | Streamlit 대시보드 | 예정 |

## 처음 실행하기

### 1. 준비
1. Python 3.10~3.13과 VS Code를 설치합니다. (변화점 탐지 패키지 ruptures가 아직 3.14용 설치 파일이 없어 3.13을 권장합니다. 3.14에서도 ruptures 없이 동작합니다.)
2. 이 폴더를 VS Code로 열고, 터미널(상단 메뉴 Terminal > New Terminal)을 엽니다.
3. 가상환경을 만들고 패키지를 설치합니다.

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Mac
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. API 키 넣기
1. `.env.example`을 복사해서 이름을 `.env`로 바꿉니다.
2. 아래 안내대로 키를 받아 `=` 뒤에 넣습니다. `.env`는 `.gitignore`에 들어 있어 GitHub에 올라가지 않습니다.

| 키 | 필수 | 발급처 |
|---|---|---|
| `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | 필수 | 네이버 클라우드 플랫폼(ncloud.com) > NAVER API HUB에서 Application을 만들고 데이터랩 검색어 트렌드 API를 추가한 뒤, 인증 정보의 Client ID / Client Secret을 복사 |
| `NCBI_API_KEY` | 선택 | NCBI 계정 로그인 > Account Settings > API Key Management. 없어도 동작하지만 있으면 PubMed 수집이 약 3배 빠름 |
| `NCBI_EMAIL` | 선택 | 본인 이메일. NCBI가 과도한 호출 시 연락용으로 권장 |
| `KIPRIS_API_KEY` | 필수(특허) | KIPRIS Plus(plus.kipris.or.kr) 회원가입 > 특허·실용신안 정보 검색 서비스를 **무료**로 신청 > 마이페이지 > APIKEY 관리의 REST AccessKey. 무료는 월 1,000회 호출 (전체 수집 약 70회) |

> **네이버 키 주의:** 2026-07-31부터 데이터랩 API 신규 키는 NAVER API HUB에서만 발급됩니다. 이 코드는 HUB 주소(`naverapihub.apigw.ntruss.com`)와 HUB 인증 헤더(`X-NCP-APIGW-API-KEY-ID` / `X-NCP-APIGW-API-KEY`)를 사용하므로, 예전 네이버 개발자센터(developers.naver.com)에서 받은 키로는 동작하지 않습니다.

### 3. 수집 실행

```bash
python src/collect_naver.py --dry-run     # 요청 계획 확인 (키 없어도 됨)
python src/collect_naver.py               # 네이버 수집 (1분 이내)

python src/collect_pubmed.py --dry-run    # 검색식 확인
python src/collect_pubmed.py --only PDRN --start 2024-01   # 시험 수집
python src/collect_pubmed.py              # 전체 수집 (키 없으면 약 15분)

python src/quick_plot.py                  # 그래프로 확인
```

### 4. PubMed 검색식 정확도 점검 (선택)

검색식에 화장품과 상관없는 논문이 섞이면 논문 수가 부풀려집니다. 성분마다 논문을 무작위로 뽑아 사람이 직접 관련 여부를 표시하고 정확도(관련 논문 비율)를 계산합니다.

```bash
python src/review_pubmed.py                       # 성분당 무작위 20편 -> data/review/pubmed_review_<날짜>.csv
# 엑셀로 열어 relevant 칸에 O(관련) / X(무관) / ?(애매) 표시 후 저장
python src/review_pubmed.py --summary data/review/pubmed_review_<날짜>.csv   # 성분별 정확도 계산
```

### 5. 특허 수집과 필터 점검

```bash
python src/collect_kipris.py --dry-run    # 검색어 확인
python src/collect_kipris.py              # 전체 수집 (약 70회 호출, 결과는 data/raw/kipris_cache/에 저장되어 다시 실행하면 0회)

python src/review_kipris.py               # 화장품 IPC 필터·식물성 PDRN 판정 점검 표본 만들기
python src/review_kipris.py --summary data/review/kipris_review_<날짜>.csv
```

### 6. 데이터 합치기와 시차 분석

```bash
python src/collect_naver.py --procedure   # 시술 검색량 (config/procedure_keywords.csv, 요청 2번)
python src/build_dataset.py      # -> data/processed/trend_long.csv
python src/analyze_lead_lag.py   # -> data/processed/onsets.csv, lead_lag.csv, w4_onsets_train.png
python src/analyze_procedure_path.py   # -> procedure_path_onsets.csv, procedure_path_yearly.csv, w4_procedure_path.png
```

### 7. 후보 성분 점수화

```bash
python src/score_candidates.py                 # 데이터 마지막 달 기준 -> scores.csv, score_backtest.csv, w5_scores.png
python src/score_candidates.py --asof 2021-06  # 과거 시점 기준으로 점수 보기
python src/assess_feasibility.py               # -> feasibility.csv, w6_feasibility.png
```

| `processed/lead_lag.csv` | lag_onset_*, ccf_best_lag, granger_* | 앞 지표가 몇 달 먼저였는지 (양수 = 논문·특허가 먼저) |

### 특허를 세는 기준
- 성분 이름(여러 표기, `keywords.csv`의 `kipris_keywords`)이 제목·요약에 들어간 특허를 출원월 기준으로 셉니다. 같은 특허는 성분마다 한 번만 셉니다.
- **화장품 특허**: IPC가 A61K 8/(화장품 성분) 또는 A61Q(화장품 용도)인 특허. 단 A61Q 중 11(치약·구강용)만 있는 특허는 뺍니다.
- **식물성 PDRN**: PDRN 특허 중 "OO 유래 PDRN", "OO으로부터 추출한 DNA"처럼 출처가 식물·해조류로 적힌 특허. 연어·미생물·줄기세포 유래는 제외합니다.

## 4주차 결과: 논문·특허가 검색보다 먼저 움직였나?

학습용 성분 4개로 확인했습니다. 시차는 개월 단위이고 양수면 논문·특허가 먼저입니다.

| 성분 | 그래프로 본 모습 | 특허 → 검색 시차 (시작점 / 교차상관) | 판단 |
|---|---|---|---|
| 나이아신아마이드 | 특허 2016년, 논문 2016년부터 꾸준히 증가 → 검색 2023년 급등 | +84개월 / +24개월 | **앞섬** |
| 레티놀 | 특허·논문 2018~2019년 상승 → 검색 2021~2022년 상승 | +41개월 / +11개월 | **앞섬** |
| PDRN | 검색 2022년 중반 → 화장품 특허 2023년 → 논문 2025년 | -7개월 / -5개월 | 검색이 먼저 |
| 시카 | 특허가 2012년부터 꾸준히 증가, 검색은 2018년에 한 번 튐 | 판단 불가 | 네이버 데이터가 2016년부터라 검색 시작 시점을 알 수 없음 |

- **H1(일정한 시차로 먼저 움직인다)은 일부만 맞습니다.** 4개 중 2개(나이아신아마이드, 레티놀)에서 특허·논문이 검색보다 1~7년 먼저 올랐지만, 시차가 성분마다 크게 다르고 방법(시작점, 교차상관)에 따라서도 달라 "N개월 뒤 뜬다"처럼 한 숫자로 예측하기는 어렵습니다.
- **PDRN은 반대였습니다.** 소비자 관심이 피부과 시술(연어 주사)에서 먼저 생기고, 화장품 특허와 논문이 그 뒤를 따랐습니다. 필러·주사제를 포함한 전체 특허로 봐도 2023년 중반에 올라 검색보다 늦었습니다. 즉 성분이 뜨는 길은 '연구 → 특허 → 소비자' 한 가지가 아니라 '시술 → 소비자 → 화장품 특허'도 있습니다.
- **그랜저 인과 검정**은 12개 시차를 여러 번 시험한 것을 보정하면 시카(특허 → 검색)만 유의했습니다. 다른 성분은 통계적으로 "특허를 알면 검색을 더 잘 맞힌다"고 말할 근거가 약합니다.
- 그래서 5주차 점수화에서는 정확한 시차로 날짜를 예측하기보다 **"특허·논문은 이미 오르는데 검색은 아직 낮은 성분"(H2)**을 찾는 방향으로 씁니다.

### 추가 검증: "피부과 시술이 뜨면 원료 회사가 움직이고, 브랜드가 움직인다"

업계 인터뷰(로레알)에서 나온 말을 가설로 세우고, PDRN에서 본 '검색이 먼저' 현상이 시술에서 출발한 경로인지 확인했습니다.

- **측정:** ① 시술 검색량(리쥬란·연어주사, 엑소좀시술, 백옥주사, MTS시술 등, `config/procedure_keywords.csv`) ② 특허를 출원인 유형(시술 제품사·원료사·ODM·브랜드사)별로 나눠 셈(`config/applicant_types.csv`, 특허 많은 상위 기업을 사람이 분류) ③ 화장품 검색량
- **시점:** 모든 단계를 같은 기간(2016-01~2025-04)으로 자르고, 평소 수준을 뺀 '늘어난 양'이 누적 25%(T25)·50%(T50)에 도달한 달을 비교했습니다.

| 성분 | 시술 검색 T25 | 화장품 검색 T25 | 원료사 특허 T25 | 브랜드사 특허 T25 |
|---|---|---|---|---|
| PDRN | 2022-01 | 2023-05 | 2023-08 | 2023-11 |
| 엑소좀 | 2020-12 | 2022-11 | 2021-12 | 2020-11 |
| 스피큘 | 2018-03 | 2019-06 | 2023-07 | - |
| 글루타치온 | 2017-04 | 2020-03 | - | - |
| 나이아신아마이드 (비교군) | 시술 없음 | 2023-02 | - | 2016-08 |
| 레티놀 (비교군) | 시술 없음 | 2022-09 | - | 2020-02 |

- **"시술이 먼저 뜬다"는 지지됩니다.** 시술 관심이 늘어난 4개 성분 모두 시술 검색이 화장품 검색보다 1~3년 먼저였습니다(T50 기준으로도 같은 순서). 펩타이드(보톡스)는 시술이 2016년 이전부터 이미 대중적이라 판단하지 않았습니다.
- **"원료사 → 브랜드" 순서는 약하게만 보입니다.** PDRN은 원료사 특허가 브랜드사보다 3개월 먼저였지만 건수가 적고(22건, 7건), 엑소좀은 T25 기준 브랜드사 특허가 1개월 일렀고 T50 기준으로는 원료사(2023-08)가 브랜드사(2023-11)보다 앞섰습니다. 또 원료사 특허는 화장품 검색과 비슷한 시기에 몰려, 특허만으로는 원료사가 소비자보다 먼저 움직였다고 말하기 어렵습니다. 원료사는 특허 없이 신원료를 출시하는 경우가 많아 특허가 원료사 움직임을 충분히 담지 못했을 수 있습니다.
- **성분이 뜨는 경로는 두 가지로 나뉩니다.**
  - *기업·연구 주도* (나이아신아마이드, 레티놀): 브랜드사·ODM 특허가 소비자 검색보다 2~6년 먼저 → 특허가 선행지표
  - *시술 주도* (PDRN, 엑소좀, 스피큘, 글루타치온): 시술 관심 → 소비자 화장품 관심 → 원료사·브랜드 특허 → 시술 검색량이 선행지표
- **원료 사업 시사점:** 시술 주도 성분은 특허가 쌓일 때쯤이면 이미 소비자 시장이 열려 있습니다. 원료사가 1~2년 먼저 준비하려면 특허보다 **시술 트렌드**를 봐야 합니다. 5주차 점수화에 시술 검색량을 별도 신호로 넣습니다.


## 5주차 결과: 후보 성분 점수화

### 점수 만드는 법 (H2: "특허·논문은 오르는데 검색은 아직 낮은 성분")
기준 달(T)에 **그때 볼 수 있던 데이터만** 써서 성분 20개(학습 4 + 후보 16)에 점수를 매깁니다.

| 항목 | 계산 | 비중 |
|---|---|---|
| 논문 모멘텀 | 최근 12개월 논문 수 / 그 전 12개월 (로그 증가율, 작은 수가 튀지 않게 양쪽에 5를 더함) | 0.3 |
| 특허 모멘텀 | 같은 계산. 특허는 18개월 뒤 공개되므로 T-18개월까지만 사용 | 0.3 |
| 검색 여지 | 최근 12개월 검색 수준이 낮을수록 높음 | 0.4 |
| 시술 신호 (별도) | 시술 검색량 증가율. 시술 검색어가 있는 5개 성분만 있어 점수에는 넣지 않고 따로 표시 | - |

각 항목은 성분 사이 백분위(0~1)로 바꿔 더합니다. 판정: 논문+특허 연 10건 미만은 *근거 부족*, 검색 수준 하위 35% 밖은 *이미 대중화*, 위쪽 신호 상위 40%이면서 검색 여지 상위 50%면 *선행 신호*, 나머지는 *관찰*.

### 현재 순위 (2026-10 기준, 특허는 2025-04까지)

| 순위 | 성분 | 점수 | 판정 | 참고 |
|---|---|---|---|---|
| 1 | 식물성 PDRN | 0.89 | 선행 신호 | 논문 연 5건·특허 20건으로 양이 적음. PDRN 인기의 파생 |
| 2 | 스피큘 | 0.79 | 선행 신호 | 시술 검색 +6% (시술 성분 중 유일하게 증가) |
| 3 | 아스타잔틴 | 0.74 | 선행 신호 | 검색이 거의 0, 특허 필터 정확도 0.7 |
| 4 | 마이크로바이옴·발효 | 0.69 | 선행 신호 | 논문 연 141건으로 근거가 가장 두꺼움 |

- 가중치를 9가지로 바꿔도(위쪽 신호 0.5~0.7, 그 안에서 특허 0.3~0.7) 식물성 PDRN·스피큘·마이크로바이옴은 9번 모두, 아스타잔틴은 8번 상위 5위에 들었습니다(`score_sensitivity.csv`).
- 엑소좀·글루타치온·PDRN·펩타이드는 시술 검색량이 전년보다 21~37% 줄었습니다. 시술 유행이 식는 신호로, 4주차 결과(시술 → 1~3년 뒤 화장품)를 따르면 이 성분들은 신규 진입보다 이미 열린 시장에 가깝습니다.

### 백테스트: 이 점수가 과거에 맞았나?
2017-12부터 2023-06까지 6개월마다 그 시점 데이터로 점수를 매기고, **그 뒤 3년 동안 검색량이 얼마나 늘었는지**와 순위상관(스피어만)을 비교했습니다(12개 시점).

| 방법 | 순위상관 평균 (범위) | 상위 5개 중 검색 2배 이상 비율 |
|---|---|---|
| H2 점수 | 0.10 (-0.04 ~ 0.45) | 30% |
| 위쪽 신호만 (논문·특허) | 0.01 (-0.12 ~ 0.24) | 37% |
| 단순 추세 (지금 오르는 검색이 계속 오른다) | 0.19 (-0.22 ~ 0.50) | 42% |
| 무작위로 고를 때 | 0 | 26% |

- **H2 점수는 과거 데이터에서 검색 증가를 거의 예측하지 못했습니다.** 성분 20개일 때 순위상관이 0.44를 넘어야 우연이 아니라고 볼 수 있는데(p<0.05), 12개 시점 중 1개만 그 근처였습니다.
- 항목별로 보면 논문 모멘텀(-0.04)과 특허 모멘텀(0.04)은 거의 0이고, 검색 여지(0.15)만 약하게 양수였습니다. 즉 성분 사이를 비교할 때 "특허·논문이 많이 늘어난 성분이 3년 뒤 더 뜬다"는 근거는 이 데이터에서 찾지 못했습니다.
- 4주차와 같은 결론입니다. 나이아신아마이드·레티놀처럼 특허가 몇 년 먼저 오른 사례는 있지만, 시차가 2~7년으로 제각각이고 PDRN처럼 시술에서 시작한 성분은 특허가 오히려 늦어서, 한 가지 점수로 묶으면 신호가 섞여 사라집니다.
- **그래서 점수는 "예측"이 아니라 "살펴볼 후보를 좁히는 거름망"으로 씁니다.** 6주차 사업성 검토는 점수 상위 성분과 함께, 시술 신호가 있는 성분(스피큘)과 이미 검색이 오르는 성분을 따로 봅니다.


## 6주차 결과: 원료 사업으로 들어갈 만한가?

5주차 상위 4개(식물성 PDRN, 스피큘, 아스타잔틴, 마이크로바이옴)에 검색이 가장 빠르게 오르는 쌀, 7위 재조합 콜라겐을 더해 6개를 봤습니다. 이미 시장이 열린 PDRN은 비교 기준으로 같이 계산했습니다.

### 평가 방법
| 축 | 항목 | 자료 |
|---|---|---|
| 시장 매력도 | 5주차 점수, 최근 검색 증가율, 효능 근거 | `scores.csv`, 웹 조사 |
| 진입 용이성 | 특허 출원 기업 수, 상위 3사 집중도, 대기업(브랜드사·ODM) 참여 | 화장품 특허 2021-01~2025-04 |
| | 규제·안전, 원료 수급, 기술 장벽 | 웹 조사 (`config/feasibility_notes.csv`에 근거와 출처) |

- 숫자 항목은 후보 6개 안에서 백분위로, 정성 항목은 1(불리)·2(보통)·3(유리)을 0~1로 바꿔 같은 비중으로 평균했습니다.
- 정성 평가는 공개 기사·업체 자료 기반의 1차 판단입니다. 식약처 공식 자료로 확인하지 못한 부분(스피큘 규제, 아스타잔틴 사용 한도)은 파일에 "확인 못 함"으로 적었습니다.
- 항목을 하나씩 빼고 9번 다시 계산해 같은 칸에 남는 횟수(`robust`)를 함께 봤습니다.

### 발견한 점
- **식물성 PDRN은 기존 PDRN 원료사가 옮겨 가는 시장입니다.** 2021~2025년 PDRN 화장품 특허 77건 중 32건(42%)이 식물·해조류 유래이고, 출원 상위 기업(바이오에프디엔씨, 지에프씨생명과학, 유니솔브, 현대바이오랜드)이 PDRN 전체 상위 기업과 같습니다. 신규 진입자에게는 빈 시장이 아니라 원료사끼리 경쟁이 시작된 시장입니다.

## 알아둘 한계
- 네이버 검색량은 절대 검색 수가 아니라 상대지수입니다. 앵커로 맞춰도 앵커보다 훨씬 작은 성분은 소수점 단위 오차가 커집니다.
- 검색량이 너무 적은 달은 네이버가 값을 주지 않아 0으로 채웠습니다.
- PubMed 검색식은 무작위 20편 O/X 점검을 최대 3차까지 거쳐 다듬었습니다(2주차). 정확도 0.5 미만이던 7개 성분 중 6개를 0.85 이상으로 올렸고, 아스타잔틴은 0.60에서 멈췄습니다(먹는 아스타잔틴의 전신 건강 리뷰가 섞임). 표본이 20편이라 정확도에는 ±20%p 정도 오차가 있습니다. 성분별 근거는 `config/keywords.csv`의 `noise_note`(`[검수 11/19]`, `[검수 11/19-2]`, `[검수 11/19-3]`)와 `data/review/`에 있습니다.
- 정확도 0.5~0.8인 CICA·RICE·MUGWORT·HEARTLEAF·EXOSOME·EGCG·RECOMB_COLLAGEN은 뚜렷한 오류 패턴이 없어 검색식을 유지했습니다.
- 푸코잔틴은 검색식을 좁힌 뒤 논문이 39편(연 3~4편)뿐이라 월별이 아니라 연도별로만 봅니다.
- PubMed 논문 수는 출판일이 아니라 PubMed 등록일 기준으로 셉니다. 출판일 기준으로 월별로 세면 온라인 선공개일과 정식 출판일이 다른 논문이 두 번 세어졌습니다(레티놀: 전체 418편인데 월별 합계 630편). 등록일은 출판일보다 보통 몇 주~몇 달 늦을 수 있어 월 단위 시점 해석에 주의합니다.
- 1주차 수집(출판일 기준)에서는 연도만 있는 논문이 1월로 몰려 1월 값이 튀었습니다. 등록일 기준으로 바꾼 뒤에도 분석 때는 연도별 합계나 12개월 이동합계를 함께 봅니다.
- 푸코잔틴·아스타잔틴·재조합 콜라겐은 네이버 검색량이 거의 0이라 소비자 지표로 판단하기 어렵고, 논문·특허 위주로 판단합니다.
- 특허는 출원 후 약 18개월 뒤에 공개됩니다. 그래서 최근 18개월(현재 2025-05 이후) 특허 수는 실제보다 적고, 분석에서는 빼고 계산합니다(`provisional`).
- 화장품 IPC 필터는 무작위 표본(성분당 화장품 10건·기타 5건) O/X 점검에서 21개 중 16개 성분이 정확도 0.8 이상이었습니다. 아스타잔틴·마이크로바이옴·재조합 콜라겐·후코잔틴(0.5~0.7)은 원료 생산·균주 특허가 섞여 있습니다. 필러·리프팅 실 같은 시술용 특허는 화장품 IPC가 아니라서 빠집니다. 결과는 `data/review/kipris_precision_<날짜>.csv`에 있습니다.
- 식물성 PDRN 판정은 표본 20건(식물 15, 비식물 5)에서 모두 맞았습니다.
- 특허 원문 목록(`kipris_items_*.csv`)과 특허 점검 표본은 요약문 원문이 들어 있어 GitHub에 올리지 않습니다. 수집 스크립트를 실행하면 다시 만들어집니다.
- 시작점은 12개월 합계·전년 대비로 잡기 때문에 실제보다 몇 달 늦게 잡힙니다. 모든 지표에 같이 적용되므로 지표 사이 시차에는 영향이 적습니다.
- 네이버 데이터가 2016-01부터라 검색 시작점은 2017-12보다 앞서 잡을 수 없습니다(`censored`). 시카처럼 그 전에 이미 뜬 성분은 시차를 잴 수 없습니다.
- 변화점 탐지는 ruptures(Dynp, 연속 직선 모델)로 계산합니다. ruptures가 없으면 같은 원리를 numpy로 구현한 예비 함수를 씁니다. 두 방식의 결과가 몇 달씩 달라 변화점은 참고용으로만 쓰고, 시작점은 전년 대비 규칙을 기준으로 합니다.
- 출원인 분류는 특허가 많은 상위 기업(대학·개인 제외)만 사람이 나눴습니다. 성분별 특허 중 분류된 비율은 12~50%(PDRN 36%, 엑소좀 50%)이고, '중' 신뢰도 분류는 추정이 섞여 있습니다. 기업 유형별 특허는 연 몇 건 수준이라 시점이 몇 달씩 흔들릴 수 있습니다.
- 시술 검색어는 시술 이름(리쥬란 등)이라 같은 시술의 다른 이름이나 병원 광고 검색이 섞일 수 있습니다.
- 백테스트는 6개월 간격 12개 시점이 서로 겹치는 3년을 보므로 독립적인 시험 12번이 아닙니다. 또 성분 20개는 2026년에 '요즘 뜨는 성분'으로 고른 것이라, 과거 시점에서 보면 결국 뜬 성분이 많이 들어 있습니다(생존 편향). 실제 예측력은 이 결과보다 낮을 수 있습니다.
- 검색 여지는 검색어 범위가 넓은 성분(예: 쌀)일수록 수준이 높게 잡혀 불리합니다. 검색이 거의 0인 성분(푸코잔틴·아스타잔틴·재조합 콜라겐)은 여지가 크게 잡히지만 실제로는 소비자 관심이 없는 것일 수 있습니다.
- 6주차 정성 평가(규제·수급·기술·근거)는 공개 기사와 업체 자료로 한 1차 판단이라 주관이 들어 있습니다. 실제 사업 판단에는 원료 견적, 식약처 고시 원문, 업계 인터뷰 확인이 필요합니다. 특허 출원인 중 개인·대학 구분은 이름 규칙으로 해서 일부 틀릴 수 있습니다.
- 학습용 성분이 4개뿐이라 시차 결론은 일반화하기 어렵습니다. 상관·그랜저 결과는 "먼저 움직인다"는 관계일 뿐 원인이라는 뜻은 아닙니다.
